Unexplored map area data (from OpenMap)
---------------------------------------
File: WalkMap_RevealData.lua
Source: OpenMap v0.8.10, Data/Forever/Reveal.lua (generated from the game's
tables, build 1.60.1.70245)
Authors: the OpenMap contributors
Project: https://github.com/openmap-world/openmap
License: MIT; the complete notice is kept at the top of the file
Modifications: the table is renamed WalkMapRevealData; the data is unchanged.
The location sharing in WalkMap_Friends.lua follows OpenMap's message format
(prefix "OpenMapLoc", MIT) so WalkMap and OpenMap users can see each other.

Layer detection (idea from LayerETA)
------------------------------------
WalkMap_Friends.lua reads your layer from a creature's GUID the way
LayerETA by Rasmus (MIT) describes it for WoW Forever: the <server> part of
"Creature-0-<server>-<instance>-<zoneUID>-...", skipping player-controlled
units. No LayerETA code is included.

Separate dependencies (not bundled)
-----------------------------------
QuestieDB by the Questie contributors supplies runtime location records.
Project: https://github.com/Questie/QuestieDB
QuestieDB (and, optionally, Questie) must be installed separately from
their own authors. No QuestieDB source files, database records or textures
are bundled with WalkMap; WalkMap_LiveDB.lua reads the installed database
during play. When Questie is installed and loaded, WalkMap uses Questie's
own live blacklist instead of the bundled copy.

World of Warcraft client artwork
--------------------------------
The addon references textures and frame templates supplied by the game.
No copies of those client assets are distributed.
